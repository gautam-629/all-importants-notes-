
## HTML Questions

1.  **What is HTML?**

    HTML (HyperText Markup Language) is the standard language used to

    structure the content of a webpage.

2.  **Difference between `<div>` and `<span>`?**

    -   `<div>` = block-level element

    -   `<span>` = inline element

2.  **What are semantic HTML tags?**
    Examples: `header`, `footer`, `nav`, `article`, `section`, `main`

3.  **Why are semantic tags important?**
    -   Improve SEO

    -   Improve accessibility

    -   Make code cleaner

2.  **Difference between HTML and HTML5?**
    HTML5 includes audio, video, canvas, semantic tags, local storage, etc.

3.  **Purpose of `alt` in `<img>`?**
    Shows alternative text if image fails to load and helps with
    accessibility and SEO.

4.  **Inline, block, and inline-block elements?*
    -   Inline: span, a, img
    -   Block: div, p, h1
    -   Inline-block: no line break + width/height allowed
  
4.  **What is DOCTYPE?**
    Defines the HTML version: `<!DOCTYPE html>`

5.  **What are meta tags?**
    Provide metadata like charset, viewport, keywords.

6. **Difference between `<link>` and `<script>`?**
-   `<link>` loads CSS
-   `<script>` loads JavaScript

## CSS Questions


1.  **What is the CSS Box Model?**
    Content → Padding → Border → Margin

2.  **What is specificity?**
    Priority order: Inline \> ID \> Class \> Tag

3.  **Pseudo-classes vs pseudo-elements?**
    -   Pseudo-class: `:hover`, `:focus`
    -   Pseudo-element: `::before`, `::after`

2.  **`display: none` vs `visibility: hidden`**
    -   `display: none`: removed from layout
    -   `visibility: hidden`: hidden but space remans

2.  **Flex vs Grid?**
    -   Flexbox: one-direction
    -   Grid: two-direction

2.  **CSS position types?**
    static, relative, absolute, fixed, sticky

3.  **What is z-index?**
    Controls stacking order.

4.  **What is a media query?**
    For responsive design.

5.  **CSS preprocessors?**
    Sass, Less.
6. **Margin vs Padding?**
-   Margin = outside
-   Padding = inside
